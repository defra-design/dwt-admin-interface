Design rationale

The client secret is only sent by email, so the Send credentials page shows it as “[Hidden]”, in the same way as the software provider page. The other credentials stay on the page, so the admin user can check what they are sending before they send it.

The page asks one question, the email address. It is someone else’s address, so the browser does not offer to fill it in.

The success alerts are on the software provider page the user goes to next, as the “Software provider deleted” alert is on the Software providers page.

Other design decisions are the same as in version 10.

This version has its own session data. Credentials created in this version are not shown in version 10, and the other way round. Clear prototype data between research sessions.
