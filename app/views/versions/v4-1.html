Design rationale

Apart from the changes above, design decisions are the same as in version 4.

Separating the environments makes the environment part of where the user is, not a question to answer or a column to read. The MoJ sub navigation shows which environment is selected and lets the user switch. It is a link list, so it works without JavaScript.

This version has its own session data. Credentials created in this version are not shown in version 4, and the other way round.
