Design rationale

Apart from the changes above, design decisions are the same as in version 4.1.

Create and edit use one page, so the journeys feel the same. The user is asked for only the client name, with the software provider name and software name in the hint.

The Client ID and Client secret are one block of text, so the user can copy it in one step and paste it into an email. Without JavaScript the Copy button is hidden and the text can be selected by hand.

This version has its own session data. Credentials created in this version are not shown in version 4, and the other way round.
