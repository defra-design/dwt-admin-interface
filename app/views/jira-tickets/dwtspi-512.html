DWTSPI-512

Show long client names in the table without scrolling sideways

Clickable prototype: No prototype version shows this yet.

{{ govukButton({ text: "View the design reference page", href: "/jira-tickets/dwtspi-512/design", classes: "govuk-button--secondary" }) }}

User story

As a member of Defra staff who uses the DWT admin portal,
I want to read a whole client name and client ID in the Software providers table without scrolling sideways,
so that I can tell clients apart and open the right one.

Context

A client name can be up to 2,048 characters, and it has no spaces, so it cannot wrap. The longest client name in Production is 67 characters. It makes the table wider than the page, and the whole page scrolls sideways. The scrollbar is at the bottom of the very long table and can easily be missed altogether.

The limit of 2,048 characters is not changing. The table needs to wrap the client name and the client ID instead.

This improves the existing solution but is not ideal. To improve usability and accessibility, we would need to introduce fields that follow standard conventions for text input, e.g. for Software provider name. That is out of scope for this ticket.

Design acceptance criteria

Changes to the Client credentials table on the Software providers page in version 8.

  1. On tablet and wider screens (641px and wider), the Client name column is half the width of the table.
  2. A client name that is longer than the column continues on the next line in the same cell.
  3. A client name or client ID that has no space can break at any character, so it never runs outside its cell.
  4. The whole client name is shown. It is not cut off and has no ellipsis.
  5. A client ID that is longer than its column continues on the next line in the same cell.
  6. A wrapped row is taller than the others. The row border and the cell padding do not change.
  7. The page matches the design reference.

Acceptance criteria

  1. Given a client name of any length up to 2,048 characters, when the table is shown, then the whole name is shown.
  2. Given the table has a long client name, when the user views the page at any width from 320px, then the page does not scroll sideways.
  3. Given a client name has wrapped onto more than one line, when the user selects it, then they go to that client’s software provider page.
  4. Given the table has a long client name, when the user sorts by a column, then the rows sort as before.

Accessibility acceptance criteria

Meets WCAG 2.2 AA:

  1. A wrapped client name is one link, and its accessible name is the whole client name. No characters, hidden text or wbr elements are added to it (2.4.4, 2.5.3).
  2. The whole client name and client ID are in the page text. They are not cut off by CSS, so screen reader and zoomed users get all of it (1.3.1, 1.4.4).
  3. The page does not scroll sideways at 320px wide or at 200% zoom, and the table does not need a scrolling container (1.4.4, 1.4.10).
  4. The cells have no fixed height or width in pixels, so no text is clipped when the user increases text spacing (1.4.12).
  5. The table keeps its caption, scope="col" on the column headers and aria-sort on the sortable headers (1.3.1).
  6. The link works with a keyboard. When the name wraps, the GOV.UK focus style, with the focus colour as the background and focus-text as the text, shows on every line (2.1.1, 2.4.7).
  7. The reading order and tab order follow the visual order, row by row (1.3.2, 2.4.3).

How to test

  • Run an automated check, such as axe or WAVE.
  • With only a keyboard, tab to the long client name and check that the focus style shows on every line.
  • Check the long client name with a screen reader, such as NVDA or VoiceOver. It is read as one link with the whole name.
  • Check the page at 320px wide and at 200% zoom. The page does not scroll sideways.
  • Check a 67-character name and a 2,048-character name.

Out of scope

  • Changing the limit of 2,048 characters, or the characters allowed in a client name.
  • Cutting a long client name short, with a “Show more” control or a tooltip.
  • Wrapping the client name on other pages, such as the software provider page.
  • Showing the table in another way on small screens, such as stacked rows.
