Last changed column

Clickable prototype: Version 4.2. Versions 4.3 and 4.4 are copies of it.

The design and acceptance criteria for this column, to use when a ticket is written for it. It has no ticket number yet. It was taken out of DWTA-456, Build the Software providers page and client credentials table. It adds a fourth column to the client credentials table, after Environment.

{{ govukButton({ text: "View the design reference page", href: "/jira-tickets/last-changed-column/design", classes: "govuk-button--secondary" }) }}

Acceptance criteria

On the Software providers page, when there are client credentials:

  1. The table has four columns, in this order: Client name, Client ID, Environment, Last changed.
  2. The Last changed column shows the date and time on two lines, for example “5 October 2026” and, below it, “at 10:15am”. This keeps the times aligned down the column.
  3. The rows are sorted by Last changed, with the newest first. This replaces the default sort by Client name, from A to Z.
  4. The Last changed column can be sorted, as well as the Client name, Client ID and Environment columns.
  5. Given I select the Last changed heading, when the table sorts, then it sorts in ascending order. When I select it again, it sorts in descending order. At the start, it is already sorted in descending order, so the first selection sorts it in ascending order.
  6. The Last changed column sorts by the date and time, not alphabetically.
  7. The page matches the design reference.

Accessibility acceptance criteria

  1. The Last changed heading is a th with scope="col" (1.3.1).
  2. At the start, the Last changed heading has aria-sort="descending", and Client name has aria-sort="none". The MoJ script turns the heading into a button and keeps aria-sort up to date (4.1.2).
  3. When the table sorts by Last changed, a screen reader announces the new order, for example “Sort by Last changed (ascending)”, and focus stays on the heading button (4.1.3, 3.2.2).
  4. The date and time are in one cell. The line break is only visual, so a screen reader reads “5 October 2026 at 10:15am” as one phrase (1.3.1).

How to test

  • Sort the table by Last changed with only a keyboard, and check the announcement with a screen reader, such as NVDA or VoiceOver.
  • Check that the times line up at 320px wide and at 200% zoom.
  • Turn off JavaScript and check that the table still shows, sorted newest first.
