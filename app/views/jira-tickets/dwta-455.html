Jira ticket DWTA-455

Update branding to a Defra internal service

{{ govukButton({ text: "View the design reference page", href: "/jira-tickets/dwta-455/design", classes: "govuk-button--secondary" }) }}

User need

As a member of Defra staff who uses the DWT admin portal, I need to know it is a genuine Defra internal tool, so that I can trust it and use it with confidence.

User story

As a member of Defra staff who uses the DWT admin portal, I want it to look and work like other Defra internal services, so that I can trust it is a genuine Defra tool and find my way around it more easily.

Context

This story updates the branding from the current live service to a Defra internal service. It covers the page layout, the header and footer, breadcrumbs, the page title, sentence case and the size and spacing of H1s.

The reason for this change is to bring the live service in line with Defra branding, as set out in Defra’s design guidance.

Components and patterns

  • Defra digital service manual header, navigation and footer, using custom app-defra-* styles because the service is not on GOV.UK. Guidance: Defra branding.
  • GOV.UK Design System typography for headings and paragraphs. Guidance: Headings.
  • GOV.UK Design System spacing between headings and paragraphs. Guidance: Spacing.

Acceptance criteria

On every page:

  1. The page content is the standard GOV.UK width of 960px.
  2. The header has a white background, with the Defra logo 60px high and 12px of padding above and below it (84px in total). The service name “DWT admin portal” is defra-green.
  3. The navigation bar is defra-green-dark, with white link text. Each link has 16px text with 12px of padding above and below (about 46px in total). The current page is bold, with a nav-current-overlay background and a 4px white bar underneath.
  4. The footer has a 10px defra-green-dark border across the top and a light-grey background. The text “Maintained by the DWT Software Provider team at Defra” is black.
  5. The page title is the page name followed by “DWT admin portal”, with no “GOV.UK”. On the home page it is just “DWT admin portal” (WCAG 2.4.2).
  6. There are no breadcrumbs.
  7. Headings, links and labels are in sentence case.
  8. The H1 is the large heading size, with the standard GOV.UK space between it and the paragraph below.
  9. The page matches the design reference.

Accessibility acceptance criteria

On every page, meets WCAG 2.2 AA:

  1. Text in the header, navigation bar and footer has enough contrast against its background: at least 4.5:1, or 3:1 for the service name, which is large bold text (1.4.3).
  2. The current page in the navigation is shown by bold text, the nav-current-overlay background and a white bar, not by colour alone (1.4.1). The link has aria-current="page" (4.1.2).
  3. The page has one banner (header), one navigation, one main and one contentinfo (footer) landmark. The navigation has a label (1.3.1).
  4. There is one H1 and headings are in order (1.3.1, 2.4.6).
  5. You can reach and use every link with a keyboard, in a logical order, and the focus state is visible: the GOV.UK focus style, with a yellow background and black text (2.1.1, 2.4.3, 2.4.7).
  6. The Defra logo image has empty alternative text (alt=""). Its link has visually hidden text, “Department for Environment, Food and Rural Affairs”, as its name (1.1.1, 2.4.4).
  7. The page has no horizontal scrolling at 320px wide or at 200% zoom (1.4.4, 1.4.10).

How to test

  • Run an automated check, such as axe or WAVE.
  • Use the page with only a keyboard.
  • Check the header, navigation bar and footer with a screen reader, such as NVDA or VoiceOver.
  • Check the page at 320px wide and at 200% zoom.

Out of scope

  • Privacy, cookies and accessibility statement links in the footer.
  • The Software providers and Reporting pages.
