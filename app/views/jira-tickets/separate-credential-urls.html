Separate URLs for production and test credentials

The design and acceptance criteria for this change, to use when a ticket is written for it. It has no ticket number yet. It changes the Software providers page built in DWTA-456, which lists Test and Production credentials together, into two pages: one for Test and one for Production.

{{ govukButton({ text: "View the Test credentials design", href: "/jira-tickets/separate-credential-urls/test", classes: "govuk-button--secondary" }) }} {{ govukButton({ text: "View the Production credentials design", href: "/jira-tickets/separate-credential-urls/production", classes: "govuk-button--secondary" }) }}

Acceptance criteria

In the service navigation:

  1. The “Software providers” item is renamed “Test credentials”. It links to the Test credentials page.
  2. A new item, “Production credentials”, follows it. It links to the Production credentials page.
  3. The two pages have separate URLs.

On each page:

  1. The page is a copy of the Software providers page, with the same table and columns.
  2. The page title is “Test credentials - DWT admin portal” or “Production credentials - DWT admin portal”.
  3. The H1 is “Test credentials” or “Production credentials”, to match the navigation item.
  4. The table lists only the credentials for that environment. Every row in the Environment column shows “Test” on the Test credentials page and “Production” on the Production credentials page.
  5. The page matches its design reference.

Accessibility acceptance criteria

  1. The navigation link for the current page has aria-current="page", and the other has not. The current page is also shown by the active style, not by colour alone (1.4.1, 4.1.2).
  2. The page title and H1 name the environment, so that a screen reader user can tell the two pages apart (2.4.2, 2.4.6).
  3. The navigation link text is the same as the H1 on the page it links to (2.4.4, 3.2.4).
  4. The navigation fits at 320px wide and at 200% zoom, without horizontal scrolling of the page (1.4.4, 1.4.10).

How to test

  • Run an automated check, such as axe or WAVE, on both pages.
  • Move between the two pages with only a keyboard.
  • Check the page title, H1 and current page announcement with a screen reader, such as NVDA or VoiceOver.
  • Check the navigation at 320px wide and at 200% zoom.

Questions to answer

  • Does the Environment column stay, now that each page shows only one environment?
  • Do both pages need an empty state?
  • Does “Create new credentials” start from each page, with the environment already chosen?
