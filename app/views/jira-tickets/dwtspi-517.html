DWTSPI-517

Show which environment users are in, and link to the other one

Clickable prototype: Version 9. This link turns on the “Tag in the header, link under a ‘Change environment’ heading” idea and opens the Software provider list page. Select “Go to Production” to see the Production page.

User story

As a member of Defra staff who uses the DWT admin portal,
I want to see which environment I am in, and to move to the other environment from the Software provider list page,
so that I do not change or copy credentials in the wrong environment.

Context

The portal shows credentials for 2 environments: External test and Production. The pages look the same in both. Only the credentials differ, so nothing else on the page tells users which environment they are in.

This story shows the environment in the header of the Software provider list page and the Software provider detail page, and in their page titles. It adds a way to move between the 2 environments on the Software provider list page. It includes a Production version of the Software provider list page.

Design acceptance criteria

Header, on the Software provider list page and the Software provider detail page

  1. On tablet and wider screens (641px and wider), a tag shows in the header to the right of “DWT admin portal”, on the same line.
  2. The tag is not a link and does not look like one.
  3. The tag is vertically centred with “DWT admin portal”.
  4. There is 24px between “DWT admin portal” and the tag. This is the header’s existing gap, not a spacing unit.
  5. The tag text is 16px, with 2px of padding above and below and 6px to the left and right.
  6. In the External test environment, the tag says “External test”. It has the modifier class govuktag--teal.
  7. In the Production environment, the tag says “Production”. It has the the modifier class govuktag--purple..

Header, below the tablet breakpoint (640px and narrower)

  1. The logo, “DWT admin portal” and the tag are stacked, in that order, aligned to the left.
  2. There is spacing unit 2 (10px) between “DWT admin portal” and the tag. This is the same on all screen sizes.
  3. There is 12px between the tag and the navigation. This is the header’s own padding, the same space as below “DWT admin portal” when there is no tag. It is not a spacing unit.

Software provider list page

  1. An H2 heading, “Change environment”, shows below the “Create new credentials” button and above the table.
  2. Below the heading is one paragraph. In External test it says “You are in the External test environment.” followed by a link, “Go to Production”. In Production it says “You are in the Production environment.” followed by a link, “Go to External test”.
  3. The link follows the sentence on the same line when there is room. The link text has no full stop.
  4. There is spacing unit 8 (50px) between the “Create new credentials” button and the heading.
  5. There is spacing unit 3 (15px) between the heading and the paragraph.
  6. There is spacing unit 8 (50px) between the paragraph and the table.
  7. On small screens, the same spacing units are used. Spacing unit 8 is 30px and spacing unit 3 is 15px.
  8. There is no tag or link between the page heading and the introduction.

Software provider list page, Production

  1. The page has the same layout as the External test page. The table shows only Production credentials, sorted by client name from A to Z. The Environment column says “Production” in every row.

Software provider detail page

  1. The “External test” tag that sat under the H1 is removed.
  2. There is spacing unit 8 (50px) between the H1 and the Client ID. On small screens this is 30px.
  1. The pages match the design reference.

Acceptance criteria

  1. Given a user is on the Software provider list page or the Software provider detail page, then the header shows the environment they are in.
  2. Given a user opens the Software provider list page in External test, then the table shows only External test credentials.
  3. Given a user opens the Software provider list page in Production, then the table shows only Production credentials.
  4. Given a user is on the External test Software provider list page, when they select “Go to Production”, then they go to the Production Software provider list page and the header tag says “Production”.
  5. Given a user is on the Production Software provider list page, when they select “Go to External test”, then they go to the External test Software provider list page and the header tag says “External test”.
  6. Given a user opens a software provider from the External test list, then the header tag says “External test” and the page has no environment tag in its content.
  7. Given a user is on any page other than the Software provider list page, then the page has no link to the other environment.

Accessibility acceptance criteria

Meets WCAG 2.2 AA:

  1. The environment is shown in the tag text, “External test” or “Production”, not by colour alone (1.4.1).
  2. The tag is inside the header landmark, after “DWT admin portal” in the reading order. It is plain text, not focusable and has no role or aria-label (1.3.1, 1.3.2, 2.4.3).
  3. The page title is the page name, then the environment, then the service name. For example, “Software providers - External test - DWT admin portal”, or “Software providers - Production - DWT admin portal”. On the Software provider detail page, the page name is the client name. On an error page the title starts with “Error: ” (2.4.2).
  4. “Change environment” is an H2. It comes after the H1 and before the table caption, which is also an H2. No heading level is skipped (1.3.1, 2.4.6).
  5. The sentence and the link are in one paragraph. The link text, “Go to Production” or “Go to External test”, names where the link goes (2.4.4).
  6. The link works with a keyboard. It has the GOV.UK focus style, with a yellow background and black text (2.1.1, 2.4.7).
  7. At 320px wide and at 200% zoom, the page does not scroll sideways. The logo, service name and tag do not overlap or get cut off (1.4.4, 1.4.10).
  8. The cells and the tag have no fixed height or width in pixels, so no text is clipped when the user increases text spacing (1.4.12).

How to test

  • Run an automated check, such as axe or WAVE.
  • With only a keyboard, go through the page. The tag is skipped and the link shows the focus style.
  • Check the page with a screen reader, such as NVDA or VoiceOver. The page title includes the environment, the environment is read in the header, and the heading and sentence are read in order.
  • Check the page at 320px wide and at 200% zoom.
  • Check both environments.

Questions for refinement

  • What should the header tag and page title show on pages that may not belong to one environment, such as the start page and Waste organisations? Do these pages exist in both environments?

Out of scope

  • A link to the other environment on pages other than the Software provider list page. Currently, the user will only be able to change environment from the Software provider list page. That is because we have no concept of a software provider, and no way to link a set of test credentials to a set of production credentials even if they are for the same provider.
