{# Email addresses as a MOJ "Add another" group. Shared by the add and edit pages, so both behave identically. Expects `values.emails`, `maxEmails`, `errors` and `focus`; the surrounding
belongs to the page including this, so each page can post to its own URL. Built as HTML rather than with the mojAddAnother macro, and without data-module="moj-add-another", so adding and removing fields happens on the server. That is the no-JavaScript baseline MOJ describes, and it lets the maximum be enforced with the standard GOV.UK error summary and error message rather than silently in the browser. https://design-patterns.service.justice.gov.uk/components/add-another/ #}
